So just start with some simple code and finally for further sutdy.

## Datasets
Datasets are not included in this repo. The FashionMNIST dataset comes from
[zalandoresearch/Fashion-MNIST](https://github.com/zalandoresearch/Fashion-MNIST).
The notebooks call `torchvision.datasets.FashionMNIST(..., download=True)`, so the
data is downloaded automatically into the local `data/` folder when you run them.

Model weights (`*.pth`) are also not included — just re-run the notebooks to
regenerate them.
